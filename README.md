# Capstone Project - Playwright Automation Testing

## Project Overview
This project focuses on automation testing of the Advantage Online Shopping website using Playwright.

## Website
https://www.advantageonlineshopping.com/

## Technologies Used
- Playwright
- JavaScript
- Node.js

## Features Tested
- User Registration
- Login
- Product Search
- Add to Cart
- Checkout
- Wishlist
- Profile Management
- order Management
- Api
